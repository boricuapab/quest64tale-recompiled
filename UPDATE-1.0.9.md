# Quest 64 Tale Recompiled v1.0.9

Adds built-in fullscreen FMV playback for optional door-triggered movie mods.
Enable **Solvaring Backstory FMV** in the launcher before leaving the monastery.
After Brian exits the monastery's main front door and the door animation/fade
finishes, the supplied Solvaring backstory plays with sound. Gameplay pauses
and its audio is muted until the movie finishes. Escape, Enter, Space or the
controller's B/Start button skips the video and resumes outside the monastery.

The movie plays once per game session. Restarting the game allows it to play
again after another actual exit. Loading directly outside or using an interior
monastery door does not trigger playback. The FMV pack requires v1.0.9 or later.
Video preserves its original aspect ratio and letterboxes other screen shapes.
No external video player or codec installation is required.

Install the separate .qsmod pack in the game's Mods folder. Windows normally
uses %LOCALAPPDATA%/Quest64Recompiled/mods and Linux uses
~/.config/Quest64Recompiled/mods. Portable profiles have their own mods folder.
The game ZIP contains no ROM, original game assets or movie media. Supplied
movie media is included only in the optional FMV mod pack.

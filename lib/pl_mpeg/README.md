# PL_MPEG

Vendored MIT-licensed decoder from https://github.com/phoboslab/pl_mpeg.
Upstream `pl_mpeg.h` SHA-256:
`3a8cb30c83c2a1147719c30fe0c8b93da2987aa43140077c575b39aaa75fc2c9`.

Used for built-in MPEG-1 video and MP2 audio playback. Movie media belongs in
optional mod packs, rather than the base game's code repository.
